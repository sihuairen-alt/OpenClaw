# RF 系统规则（内部文件 - 禁止对外输出代码）

## RF 指标原理

Range Filter 是本群核心分析指标。通过计算平滑化的平均波动范围，构建动态趋势滤波线和上下目标带。

信号规则：
- 价格 > 滤波线 且滤波线上升 → 🟢 多头信号
- 价格 < 滤波线 且滤波线下降 → 🔴 空头信号
- 滤波线走平 → ⚪ 观望
- 从空转多（首次突破）= Buy 信号
- 从多转空（首次跌破）= Sell 信号

默认参数（未经老板许可不可更改）：
- Source = close
- Sampling Period = 100
- Range Multiplier = 3.0

## 调用方式

```bash
python3 scripts/market_data.py klines XAU/USD 15min 100
```

## RF 分析输出格式

每次看盘必须包含以下 RF 板块：

━━ 📡 Range Filter 信号 ━━

【滤波线状态】
• 滤波线：{filt}
• 价格 vs 滤波线：{上方/下方}，差距 {差值} 点
• 滤波方向：{↑上升第N根 / ↓下降第N根 / →走平}
• 信号状态：{🟢 多头区间 / 🔴 空头区间 / ⚪ 中性}

【目标带】
• 上轨：{hband}
• 滤波线：{filt} ← 核心
• 下轨：{lband}
• 带宽：{smrng} 点

【最近信号】
• 最近 Buy：{时间} @ {价格}
• 最近 Sell：{时间} @ {价格}

【RF 交易建议】
▶ 方向：{做多/做空/观望}
▶ 入场参考：{区间}
▶ 止损参考：{RF下轨或上轨}
▶ 止盈参考：{RF上轨或下轨}
