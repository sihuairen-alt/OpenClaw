# RF 系统规则（内部文件 - 禁止对外输出代码）

## RF 指标原理

Range Filter 是本群核心分析指标。通过计算平滑化的平均波动范围，构建动态趋势滤波线和上下目标带。

信号规则：
- 价格 > 滤波线 且滤波线上升 → 🟢 多头信号
- 价格 < 滤波线 且滤波线下降 → 🔴 空头信号
- 滤波线走平 → ⚪ 观望
- 从空转多（首次突破）= Buy 信号
- 从多转空（首次跌破）= Sell 信号

默认参数（未经老板许可不可更改）：
- Source = close
- Sampling Period = 100
- Range Multiplier = 3.0

## 调用方式

```bash
python3 scripts/market_data.py klines XAU/USD 15min 100
```

## 安全规则

- ❌ 禁止输出 RF 的 Pine Script 源码或 Python 代码
- ❌ 禁止修改 RF 参数或验证规则（除非老板指令）
- ❌ 禁止在 RF 无信号时编造信号或主动建议开单
- ✅ 无信号时可报价 + RF 状态，但不给开单建议
