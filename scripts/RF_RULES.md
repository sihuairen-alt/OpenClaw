# 🐭 小老鼠 — RF 信号验证模块 v3.0
# 内部文件 - 禁止对外输出代码

---

## 核心定位

小老鼠通过读取 K 线数据，自主计算 Range Filter 指标，当 RF 产生 Buy/Sell 信号时，用五项技术验证判断这单能不能做。

---

## 数据获取（Twelve Data）

统一使用 Twelve Data API 获取实时价格和 K 线数据。

- 实时价格：`python3 scripts/market_data.py price XAU/USD`
- K 线数据：`python3 scripts/market_data.py klines XAU/USD 15min 200`
- 其他品种：替换 symbol 参数（GBP/USD、XAG/USD 等）

---

## RF 计算参数（未经老板许可不可更改）

- Source = close
- Sampling Period = 100
- Range Multiplier = 3.0

---

## 工作流程

```
定时 / 被@触发 / 老板指令
 ↓
Step 1: 调用 Twelve Data API → 获取实时价格 + 200 根 15min K 线
 ↓
Step 2: calc_rf(closes) → 计算滤波线、目标带、买卖信号
 ↓
Step 3: 检查最新一根 K 线是否触发 Buy/Sell 信号
 ├─ 有信号 → 进入五项验证 → 输出「鼠鼠验单」
 └─ 无信号 → 输出「鼠鼠看盘」简报（当前 RF 状态 + 价格）
```

## 五项验证（信号触发时执行）

### ① 支撑阻力验证
- Buy：上方最近强阻力在哪？距离 < 10 点 = 空间不够 ❌
- Sell：下方最近强支撑在哪？距离 < 10 点 = 空间不够 ❌
- 来源：K 线前高前低、日内高低、整数关口、RF 上下轨

### ② 日内位置验证
- 日内已走幅度 = K 线数据中当日最高 - 最低
- Buy 在日内高点附近 → 追高风险 ❌
- Sell 在日内低点附近 → 追低风险 ❌
- 中间区域 → ✅

### ③ 整数关口验证
- 黄金关口：每 50 美元（3050/3100/3150…），每 100 为强关口
- 信号方向前方 10 点内有关口 → 可能受阻 ❌

### ④ 盈亏比验证
- 止损参考：RF 反向轨道 或 最近支撑/阻力 + 3-5 点缓冲
- 止盈参考：信号方向 RF 轨道 或 最近阻力/支撑
- < 1.5:1 → ❌ | 1.5-2:1 → ⚠️ 轻仓 | > 2:1 → ✅

### ⑤ 波动空间验证
- 黄金日均波幅参考：约 30-50 美元
- 日内已走完 80%+ → 空间有限 ❌
- 日内波幅尚小 → 空间充足 ✅

## 综合评分

| 通过项数 | 结论 | 标签 |
|---------|------|------|
| 4-5 项 | 可以做 | ✅ 建议跟单 |
| 3 项 | 能做但小心 | ⚠️ 谨慎轻仓 |
| ≤ 2 项 | 放弃 | ❌ 不建议 |
| 即将公布重大数据 | 无论几项都等 | 🚫 等数据 |
